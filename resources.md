## Generators (procedural / synthetic)

- `code/arc_1d/` — Rust binary; produces 1D-ARC-like tasks. Builds with
  `cargo build --release`. Useful when we need *guaranteed-novel* tasks.
- `code/shape_blind/image_generation_code/*.ipynb` — Jupyter notebooks
  to generate regular polygons, abstract shapes, and annotated VC-CoT
  variants in arbitrary quantity.
- We will likely also write a small in-house Python generator that emits
  ASCII-grid and vertex-list representations of novel 2D shapes with
  controllable repetition; the literature gives us templates to copy
  (PVD schema, Curse-of-CoT prompt format).

## Resource-gathering notes

### Search strategy
- Paper-finder service was not running (timed out); fell back to
  WebSearch + direct arXiv PDF download.
- Searches covered: LLM spatial reasoning, CoT vs direct, in-context
  learning + pattern induction, novel polygons, ASCII grids, vector
  graphics, repetition / self-reinforcement.

### Selection criteria
- Direct relevance to the hypothesis (reasoning vs. direct addressing
  of novel 2D geometries).
- Recency (preferred 2024–2025) tempered with foundational older work
  (Chollet 2019 ARC; ICL-Repetitions 2024).
- Code or dataset availability — every primary reference comes with a
  cloneable repo.

### Challenges
- arXiv API (`arxiv` Python lib) was rate-limited (HTTP 429); used
  WebSearch + direct `curl` of `arxiv.org/pdf/<id>` instead.
- Semantic Scholar API also rate-limited; not used.
- Paper-finder local service unavailable in this environment.

### Gaps / workarounds
- No single dataset matches our exact task (verbal addressing of *novel*
  2D geometries with *controlled repetition*). We will likely *combine*
  pieces — ARC/MiniARC for novel patterns + Shape-Blind for novel
  polygons — plus a small in-house generator for the repetition axis.

## Recommendations for experiment design

1. **Primary dataset.** MiniARC (149 tasks, 5×5 grids) for the symbolic-
   grid arm — small enough for an exhaustive sweep across models and
   prompting conditions, large enough to be statistically meaningful.
   Validate with a subsample of ARC-AGI (835 tasks).
2. **Secondary dataset.** Shape-Blind regular + abstract polygons,
   re-encoded as vertex lists or ASCII outlines, for the novel-polygon
   arm. Bonus: gives a clean MLLM-vs-LLM comparison if we want one.
3. **Conditions to vary.**
   - *Reasoning level*: direct / CoT / (where available) thinking-token
     budget.
   - *Repetition count*: 1, 2, 4, 8, 16 identical demonstrations.
   - *Representation*: ASCII grid vs vertex-list/PVD.
4. **Baselines to include.** Direct (0-shot), Direct (few-shot, K=3),
   CoT (zero-shot "think step by step"), and at least one structured-
   prompt baseline (VC-CoT-style vertex labelling or VoT-style
   re-rendering).
5. **Code to adapt.** Prompt builders in `code/cot_icl_eval/utils/`
   plug-and-play for the symbolic-grid arm. For the polygon arm, the
   evaluation loop in `code/shape_blind/evaluation/` plus the PVD
   templates in `code/vdlm/prompts.py` give us a clean starting harness.
6. **Metrics.** Exact-match accuracy; accuracy-per-1k-output-tokens (to
   normalise across CoT's higher cost); accuracy as a function of
   repetition count.
